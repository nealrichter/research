\begin{abstract}
This document walks through \texttt{microgpt\_dpo.py}, which implements Direct Preference Optimization (DPO) on top of a LoRA-finetuned microgpt model. DPO aligns a language model to human preferences without training a separate reward model, using a closed-form loss derived from the RLHF objective. The implementation demonstrates: dual model inference (policy + frozen reference), preference pair training, and the complete DPO loss computation---all in pure Python with zero dependencies.

This is Stage~3 of the teaching pipeline: \textbf{pretrain} (\texttt{microgpt.py}) $\to$ \textbf{LoRA SFT} (\texttt{microgpt\_sft.py}) $\to$ \textbf{DPO} (this file). An optional visualization module (\texttt{microgpt\_viz.py}, invoked via \texttt{--viz}) renders ASCII loss sparklines and attention heat maps. An example training run is included as an appendix.

\medskip
\noindent Source: \url{https://github.com/nealrichter/research/blob/main/microgpt/microgpt_dpo.py}
\end{abstract}

\section{The DPO Loss}

DPO~\cite{rafailov2023direct} collapses the 3-stage RLHF pipeline into one loss:
\[
\boxed{\mathcal{L}_{\text{DPO}} = -\mathbb{E} \left[ \log \sigma\!\left( \beta \left( \log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)} \right) \right) \right]}
\]

Derived from the RLHF objective: $\max_\pi \mathbb{E}[r(x,y)] - \beta\,\text{KL}[\pi \| \pi_{\text{ref}}]$.

The implicit reward is $r(x,y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$ --- the model \textit{is} the reward model.

\section{Log-Probability Computation}

\[
\log \pi(y|x) = \sum_{t=1}^{|y|} \log P(y_t \mid x, y_{<t})
\]

\begin{lstlisting}[firstnumber=231]
def log_prob_policy(prompt_tok, resp_tok):
    """Returns Value (differentiable)"""
    tokens = prompt_tok + resp_tok
    n = min(block_size, len(tokens) - 1)
    keys, values = [[] for _ in range(n_layer)], [[] for _ in range(n_layer)]
    log_p = Value(0.0)
    resp_start = len(prompt_tok)
    for pos_id in range(n):
        logits = gpt_policy(tokens[pos_id], pos_id, keys, values)
        if pos_id >= resp_start - 1 and pos_id < len(tokens) - 1:
            probs = softmax(logits)
            log_p = log_p + probs[tokens[pos_id + 1]].log()

\section{DPO Training Loop}

\begin{lstlisting}[firstnumber=358]
            # Policy log probs (differentiable)
            log_pi_chosen = log_prob_policy(prompt_tok, chosen_tok)
            log_pi_rejected = log_prob_policy(prompt_tok, rejected_tok)

            # Reference log probs (frozen, float)
            log_ref_chosen = log_prob_ref(prompt_tok, chosen_tok)
            log_ref_rejected = log_prob_ref(prompt_tok, rejected_tok)

            # DPO loss
            reward_chosen = log_pi_chosen + Value(-log_ref_chosen)
            reward_rejected = log_pi_rejected + Value(-log_ref_rejected)
            logit = (reward_chosen + (reward_rejected * -1)) * beta
            loss = (sigmoid(logit).log()) * -1
\end{lstlisting}

The loss decreases when $\pi_\theta$ assigns relatively higher probability to chosen over rejected (vs.\ reference).
